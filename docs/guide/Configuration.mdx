# Configuration

`plugins/PEUtils/config.yml` is created from the default resource the first time the plugin enables.

```yml
logging: true
imagefolder: mapImages
```

| Key | Default | Read by | Effect |
| --- | --- | --- | --- |
| `logging` | `true` | `PEUtils.log` | When true, creating a missing map id logs `Map created with id` plus the id. A missing image uses Denizen `Debug.echoError` and ignores this key. |
| `imagefolder` | `mapImages` | `PEImageMap` | Folder under `plugins/PEUtils/` that holds png files. The command joins this name, a slash, and `filename`. |

The image folder is created in `onEnable` only. `/reload` calls `reloadConfig()` and does not create a folder you renamed. Restart the server after changing `imagefolder` if the new directory does not exist yet.

`peimagemap` reads the config at execution time. After a successful config reload, the next `peimagemap` uses the new folder name.

If `imagefolder` is missing from the file, the command passes a null folder into the path and looks under `plugins/PEUtils/null/`. The enable path falls back to `mapImages` only when it creates the directory. Keep the key in the file.

`logging: false` does not silence Denizen debug errors.
